## 📚 Sobre

Esse repositório é onde eu guardo as atividades que a matéria de POO manda no curso de Ciência da Computação (IFNMG). Além das atividades, também deixo aqui alguns estudos extras que faço por conta própria, tudo em Java.

## 🗂️ Organização

Cada atividade fica numa pasta própria dentro de `src`, numerada na ordem em que foi passada:

```
src/
├── atv05/
├── atv06/
├── ...
├── atv16/
│   ├── app/
│   ├── excecao/
│   ├── modelo/
│   └── Servico/
├── atv17/
└── atv18/
```

## 💡 O que dá pra encontrar aqui

- Classes, herança e polimorfismo
- Classes abstratas e interfaces
- Tratamento de exceções
- Leitura e escrita de arquivos
- Serialização de objetos
- Menus no console com `Scanner`

## ▶️ Como rodar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Pedromaress/atividades.java.git
   ```
2. Abra a pasta no IntelliJ IDEA
3. Vá até a pasta da atividade que quiser ver e rode a classe `Main`
